# Member Portal User Manual: My Sakthi Marketing

## 1. Overview
The Associate Member Portal (`/member`) enables marketing associates to manage their referral network, track commission earnings, view downline trees, and request bank payouts.

---

## 2. Key Member Modules

### A. Associate Dashboard (`/member/dashboard`)
- Displays available wallet balance, total earnings, direct referral count, and total team size.
- Contains one-click referral link copier (`https://mysakthimarketing.in/register?sponsor=MSM...`).
- Visualizes monthly earnings trends using Recharts.

### B. Direct Referrals (`/member/referrals`)
- Lists all direct team associates registered using your sponsor code.
- Export referral list to CSV.

### C. Downline Network Tree (`/member/network-tree`)
- Interactive visualizer displaying multi-level team hierarchy.

### D. Earnings Ledger (`/member/earnings`)
- Audit itemized commission credits and reward payouts.

### E. Payout Requests (`/member/payouts`)
- Submit withdrawal requests against available wallet balance.
- Requires transaction password verification.

### F. Bank Details & Profile (`/member/profile`)
- Update personal contact info, change login and transaction passwords.
- Bank account numbers are masked (`XXXXXX1002`) for data privacy.
