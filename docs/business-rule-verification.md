# Business Rules Verification & Company Sign-Off Document

The following business rules are currently implemented in software logic and require official confirmation from **My Sakthi Marketing** leadership before live commercial production launch:

---

## 1. Membership & Sponsor Verification
- [ ] **Sponsor Verification**: Registration requires a valid active Sponsor User Code (e.g. `MSM10001`).
- [ ] **Distributor ID Format**: Prefix `MSM` followed by 5 sequential numeric digits (`MSM10001`, `MSM10002`).
- [ ] **Dual Passwords**: Members set separate Login and Transaction Passwords.

---

## 2. Commission & Reward Rules
- [ ] **Direct Referral Commission**: Fixed percentage or flat fee structure per associate registration.
- [ ] **Milestone Reward Tiers**: Specific team volume qualification requirements.
- [ ] **Commission Approval Workflow**: Admin review vs automatic DB credit.

---

## 3. Financial Payout & Bank Account Parameters
- [ ] **Payout Minimum Threshold**: Minimum wallet balance required to request payout (e.g. ₹500).
- [ ] **Payout Processing Days**: Processing SLA (e.g. 24-48 business hours via IMPS/NEFT).
- [ ] **Bank Details Audit**: Administrative verification requirement before disbursement.

---

## 4. Legal Policies & Content Approval
- [ ] **Terms & Conditions**: Legal approval of associate agreement terms.
- [ ] **Privacy Policy**: Personal data & bank masking disclosure.
- [ ] **Disclaimer**: Regulatory disclaimer regarding associate income guarantees.
